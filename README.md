# Ace Apps

Company landing page for Ace Apps (RigRoute and related products).

## Live URL
https://ace9x.github.io/ace-apps/

## Custom domain
1. Buy a domain (e.g. aceapps.com).
2. Add a `CNAME` file in this repo containing the bare domain.
3. In GitHub → Settings → Pages → Custom domain, enter the domain and enable HTTPS.
4. At your DNS host, add the records GitHub shows (usually A/ALIAS/CNAME).
